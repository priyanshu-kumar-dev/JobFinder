# 💼 JobFinder – Full Stack Job Portal

A modern, responsive, full-stack job portal built using the **MERN Stack**. JobFinder connects job seekers with recruiters through an intuitive platform where users can explore opportunities, apply for jobs, and manage their career journey.

## 🚀 Features

### 👨‍💻 For Job Seekers
- User registration and login
- Browse and search job opportunities
- Filter jobs by location, category, and job type
- View detailed job descriptions
- Save and remove bookmarked jobs
- Apply for jobs with resume
- Track application status
- Manage profile and account settings

### 🏢 For Recruiters
- Recruiter authentication
- Recruiter dashboard
- Post new job opportunities
- Manage posted jobs
- View applicants
- Update application status
- Manage company profile

### 🔐 Security & Authentication
- JWT-based authentication
- HTTP-only cookie authentication
- Protected routes
- Role-based access control
- Password hashing

## 🛠️ Tech Stack

| Frontend | Backend | Database & Tools |
|---|---|---|
| React.js | Node.js | MongoDB |
| Tailwind CSS | Express.js | Mongoose |
| React Router | REST APIs | Git & GitHub |
| Framer Motion | JWT | Postman |
| Lucide React | Cookie Parser | Cloudinary |
